Hytale for creators: mods, servers and the official tools

Java plugins, JSON assets, Blockbench, Asset Editor, Node Editor, Trigger Volume and the mod browser: how creating for Hytale works.

"Anything we do, you can do as well." That is how Hypixel Studios sums up Hytale's goal for creators. The game was built with the same tools that end up in the community's hands, and almost everything in it can be changed, extended or removed. This guide gathers what the official notes and the game files show about mods, servers and tools as of September 2026.

How mods work

Everything happens on the server

In Hytale, even singleplayer runs on a local server of your own. So when the studio talks about servers, it means both cases. The core principle, laid out by technical director Slikey in November 2025, is server-side first. You can join any modded server without downloading external mods or client packs. In singleplayer, you pick the mods for each save.

The idea goes back to 2019. The server technology post already said that when you join a server, the client automatically downloads everything it needs: models, animations, sounds and the rest.

The flip side: there are no client mods. The studio says it wants "one community, one client", without a different modified client for every server. The client stays stable, secure and the same for everyone, and the variety comes from servers.

The four kinds of content

According to the modding post, nearly every mod falls into one of these categories:

  • Server plugins: .jar files in Java. They change the server programmatically and are used for minigames, economies, commands, custom logic and new asset types.
  • Data assets: JSON files that define blocks, items, NPCs, world generation, drop tables and loot.
  • Art assets: models, textures and sounds, made with Blockbench.
  • Save files: entire worlds and prefabs, which are ready-made builds.

What the game files show

The server code has been published through the Hytale Shared Source program since June 2026, with the Java server, the assets and the network protocol. Looking at the pre-release files from 17 September, you can see how the game itself is put together:

  • The game is made of plugins. The builtin folder has 62 internal plugins, and each uses the same manifest.json format as the example plugin: Group, Name, Version, Main, ServerVersion and dependencies. Systems such as Memories, portals, shops, reputation and Chapter 1's goblin lab are plugins.
  • A lot of it is just data. The HytaleAssets/Server folder has 34 data types, from Item and NPC to TriggerVolumes, EncounterManager, WorldEvent, PortalTypes and ScriptedBrushes. The items folder alone has more than 7,000 JSON files, and the NPC folder more than 1,600.

Two practical rules from the notes for plugin makers:

  • Since Update 5, ServerVersion accepts semver ranges, such as ^0.5.0.
  • Client and server must be on the same protocol version. Update 6 moved the protocol from hytale/2 to hytale/3, and servers and plugins had to be recompiled.

Why there is no Lua

The studio said plainly that it does not have and does not intend to add text-based scripting such as Lua. Its argument is that a scripting language is still programming: programmers end up juggling two languages, and non-programmers still have to learn programming concepts. The chosen path is visual scripting, inspired by Unreal's Blueprints. Designers build logic visually, and programmers add new nodes in Java. Visual scripting has not been released yet.

The official tools

Blockbench

Hytale works with Blockbench for modelling and animation. The official plugin replaced the studio's own older tools, including the Hytale Model Maker shown in 2019. You create models, textures and animations for characters, creatures and props and bring them into the game. The studio has published video tutorials that go from concept to finished model.

Asset Editor

This is the editor for data assets. At launch it covered most asset types, with limits around NPCs, world generation and interactions. In Update 2 it gained documentation in its tooltips. The studio is rebuilding the editor on NoesisGUI, the same framework as the game's new interface, with a dockable asset browser and a new properties panel. Since September, banning someone from a server also cuts their access to the Asset Editor.

Node Editor

It shipped as an unfinished internal editor, used for world generation, Creative brushes and NPCs. The studio preferred to release it and improve it rather than hide it. In Update 5 it started running on macOS and Linux. In Update 7 it gained a start screen with recent files, light and dark themes, a graph minimap, node snapping, an interactive curve graph and fixes for large graphs. The plan is to integrate the node editors into the Asset Editor as a single suite.

Trigger Volume

It arrived in Update 5 and is the easiest way to build events without code. These are invisible 3D volumes, shaped as a box, sphere or cylinder, that fire effects when something happens inside them. There are more than 20 ready-made effects, such as playing a sound, changing the weather, teleporting, changing the game mode, spawning an NPC and placing a prefab. Conditions decide when an effect fires.

Update 6 added events such as On Entity Died and the Entity Count condition, which together build fights where you must defeat every enemy to move on. Update 7 let triggers set respawn points and move the world spawn.

Encounter Manager and world events

Chapter 1's boss fight uses the Encounter Manager, which coordinates phases, waves and arena changes. Encounters are content, not engine code, so modders can build their own. The EncounterManager folder in the files ships ready-made examples, such as Example_Boss.json. According to the Update 7 notes, that example boss forces a Blood Moon in Phase 1 and clears the sky when it dies. Update 6 added World Events, for multi-stage events across the world.

Creative, Machinima and UI

Creative's tools, such as brushes, selection and prefabs, are covered in Hytale's game modes. Machinima, the tool that recorded the 2018 trailer, is being rewritten. The new version should record gameplay as editable replays and let several players edit the same scene together. For interfaces, the studio is consolidating everything on NoesisGUI. In July, the estimate for a new server-side custom UI was one to two months.

The mod browser

The mod browser arrived in Update 6 and lives in the main menu:

  • Featured, popular and recently updated mods.
  • Category filters and search by name and description.
  • A page for each mod with description, images, download count, compatible versions and an install button.
  • The My Library screen, to view, update or remove what is installed. New installs are queued.

In Update 7, categories got readable names, and installing from the browser started working even when the mod's files are already in the folder.

There will be no paid mods in the browser. Hypixel Studios said it intends to let players support mods directly and receive exclusive cosmetics made by the official team in return. The idea is to grow this into a rewards system so creators can earn income, with teams and earning splits in the future.

Mods can also bring entire worlds. Since the Update 6 hotfixes, a world created from a mod keeps existing if the mod is removed, and the game asks for confirmation first, because a world can bring mods that run code on your computer.

Dedicated servers

Code open for reading

Since 2019 the plan has been the same: the server is shared source, meaning anyone can read the code, while the client stays closed. The server is written in Java and the client in C#. The official repository has two patchlines: pre-release, updated every week, and release, with the major updates. To build the server from source, the README asks for Java 25, and the --validate-assets option checks whether assets are valid. Official documentation lives at docs.hytale.com. Access requires accepting the Shared Source license.

What the notes changed for hosts

  • Update 2: automatic server updates, configured in UpdateConfig.
  • Update 5: reworked permissions. You can give a friend a role instead of using /op, with inheritance and namespaces.
  • Update 6: the whitelist became the hytale.server.join permission. The CrashRecovery policy arrived, along with the /maxviewradius command, from 1 to 512 chunks with a default of 32, and plugin-replaceable ban systems.
  • Update 7: the server refuses to start if it would write data inside the launcher's install folder, which every update overwrites. It exits with code 11 and explains how to move. The --allow-install-dir option forces that folder anyway. The /auth login browser and /auth login device commands work even when the server is already logged in.

Server Discovery

The official server list arrived in Update 5. Owners register their server under Server Profiles, on the Hytale account page, and choose:

  • One of nine types: Survival, Adventure/RPG, Creative, PvP, Minigames, Roleplay, Social, Sandbox or Other.
  • An audience tag: Everyone, Teen or Mature.
  • The regions served, from ten options.

The domain is verified with a TXT record, and every listing goes through moderation. Once approved, the server sends a heartbeat every two minutes. If it goes silent for more than two minutes, it drops off the list until it comes back. It is one listing per game profile. Orbis Hytale's server list mirrors that catalog.

Money

The December 2025 FAQ set the rules. Hypixel Studios takes 0% for the first two years from any server or modder who monetizes their work. After that, the cut will never exceed 20%. Servers can override cosmetics to match their theme, or sell their own cosmetics for their server only, but the studio asks them to keep supporting the official cosmetics. For mods, the request is not to override the official cosmetics.

A community that becomes the team

  • The New Worlds Modding Contest, run with CurseForge, handed out US$100,000 in prizes to 65 winners. The studio said it used the contest to find talent.
  • In Update 3, Hypixel Studios said several hires came straight from the modding community.
  • Update 6 was the first with community code accepted into the game, and one of the contributors, MelodicAlbuild, was hired.
  • The studio also said it plans to open bounties for specific server improvements.

What is still missing

The studio itself admits modding is in "early access". Visual scripting has not shipped. The node editors are not yet integrated into the Asset Editor. Part of the client's behavior is not exposed to the server, and the documentation is still incomplete. The official advice applies to every creator: back up your worlds and creations often. Meanwhile, the official minigames promise to open up even more code, with libraries and paradigms drawn from 13 years of the Hypixel Server.
