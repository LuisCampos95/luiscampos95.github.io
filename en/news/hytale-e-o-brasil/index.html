Hytale and Brazil: Portuguese in the game, community and servers

Brazilian Portuguese since Update 3, how to help translate, the Portuguese names and how many official list servers serve South America.

Hytale launched in Early Access on 01/13/2026 in English only. A month later, Brazilian Portuguese was already in the game, as one of the first two new languages. Since then, the official server list has added a South America region, and the Brazilian community keeps busy with servers, translations and wikis. This is a snapshot of Hytale in Brazil today, using only what can be confirmed.

The cover is the image from the Update 3 notes, the update that brought Portuguese. Image: Hypixel Studios (hytale.com).

Before launch

Official. In the first FAQ, from December 2025, the studio said the game would start in English only, but that it was already built with localization in mind. The plan was to use Crowdin, with community help. In the same FAQ, it said it was working to make regional pricing possible as soon as it could.

Portuguese arrived in Update 3

Official. Update 3, released on 02/17/2026, added Brazilian Portuguese and Russian as the game's first new languages. The notes thank the community translators, who were central to the work, and kicked off the first phase of localization.

Update 3 also reworked the interface to fit translated text:

  • Item tooltips were rebuilt.
  • Some screen elements got bigger.
  • The game started pulling characters from fallback fonts when one is missing, which opened the way for non-Latin alphabets.

Details of that update are in the Update 3 article.

The languages that came next

  • Update 4: Ukrainian.
  • Update 5: Simplified Chinese. Dutch, Finnish, Italian and Norwegian opened for translation on Crowdin.
  • Update 5: bug reports got a category just for translation mistakes.
  • Update 6: news tiles on the main screen show up in the system language for players using the system language option. A single mistake in a translation file also stopped blanking every name in the game.

How to help with translation

Official. According to the Update 5 notes, the path is simple: create a Crowdin account, open Hytale's project page, pick the language and apply. Once approved, you can start submitting translations.

Found a wrong text while playing? Use the in-game bug report and choose the translation category.

Names in Portuguese

In the files. The game's translation gives places and systems their own names. A few examples players see on screen:

  • The zones: Campos Esmeralda, Areias Uivantes, Fronteiras do Sussurro Gélido and Terras Devastadas.
  • The portal to the Fragments: Ancient Gateway, "Portal Ancestral" in Portuguese.
  • The invasion inside Fragments: "Fenda do Vazio".
  • The Chapter 1 hub: "Templo Esquecido", subtitled "Borda do Eco".
  • Creatures like the Goblin Feastmaster and the Mosshorn.

Not everything is translated. Texts marked as placeholders in pre-releases and some new creatures, like the Revenant Guardian, still show up in English. That is normal: translation lands after content.

The Portuguese names on this wiki come straight from the game's language files. When the official translation changes a name, the wiki changes with it.

South American servers

Official. In April 2026, the studio opened the official server lists. Operators pick the regions they serve from ten options, and South America is one of them. The in-game server browser shipped with Update 5. The list can be sorted by featured, likes and favorites. Live player counts do not exist yet, and the studio said they come later.

In the wiki's data. The Orbis Hytale servers page mirrors the game's official list. In the 09/23/2026 update, there were 162 servers. Of those, 57 list South America among their regions, and 11 serve South America only.

These numbers change every day. New servers join, and idle servers drop off the list when they stop responding.

The community

Orbis Hytale has been around since 12/15/2018 and runs this wiki in Portuguese, English and Spanish, with items, recipes, creatures and drops pulled from the game files. Daily news goes out on Instagram @brasilhytale, and the conversation happens on Discord.

Want to start now? The first steps guide and the mods and servers list are good starting points.

Summary

  • Brazilian Portuguese in the game since Update 3, on 02/17/2026.
  • Translation is done with the community, through Crowdin.
  • Translation mistakes are reported in the game itself, under the translation category.
  • The official server list has a South America region.
  • On 09/23/2026, 57 of the 162 listed servers served South America.
