How to join a Hytale server

What the address is, where to paste it and why some servers only show up on the pre-release.

by OrbisHytale · September 18, 2026

A Hytale server is a world that keeps running even when you log off. Each one has an address, and that address is what you need to join.

The address

It looks like a website: play.example.com. Sometimes it ends with a colon and a number (play.example.com:11260) — that number is the port, and it is part of the address. Copy all of it.

On our server list you can click the address and it goes straight to your clipboard.

Where to paste it

In the Hytale client the server list lives in the main menu. You add a new server, paste the address, and it stays in your list from then on.

The official in-game list

Hytale has an official list inside the game — that is where the servers, likes and favourites you see on the wiki come from. Liking and favouriting happens in game; the wiki only shows the number.

Release and pre-release

The game has two lines: the normal version and the pre-release (the test one). A pre-release server does not show up for people on the normal version, and the other way around. If a server you saw on the wiki does not show up for you, check whether it is marked pre-release and which version you are running.

Region

Every server declares which regions it serves. A server marked South America will feel better from Brazil than one that is NA East only. It does not stop you from joining — it only changes the ping.
